# arinjaysystems.com

The website for Arinjay Business Systems, built with Jekyll and hosted free on GitHub Pages.

## Change the words
- Homepage: `index.html`
- Contact details (WhatsApp, email, LinkedIn): `_config.yml`
- Footer: `_includes/footer.html`

## Add your photo
Put the photo in `assets/img/` (for example `arinjay.jpg`, portrait, about 640 × 800) and set `photo: /assets/img/arinjay.jpg` in `_config.yml`.

## Publish a Redlines post
1. Copy `_drafts/how-to-write-a-redline.md`.
2. Save it as `_posts/YYYY-MM-DD-short-title.md`.
3. Commit. GitHub rebuilds the site in about a minute. The Redlines link and the homepage section appear once the first post exists.
